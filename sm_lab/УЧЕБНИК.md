# Учебник SMLab

Версия библиотеки `0.9.0`. Каталог примеров — `sm_lab`. Команды ниже запускаются из него.

SMLab — песочница для крошечных рекуррентных сетей. Нейрон здесь короткий организм: он возбуждается, устаёт и возвращается к покою. Обучения и градиентов внутри сети нет. Поведение собирается из трёх вещей: форма графа, усталость и внешний стимул.

Сети нарочно маленькие, меньше десяти тысяч параметров. Это не фреймворк для продакшена и не модель языка. Это место, где видно, откуда берётся ритм, память, ползание и привыкание.

## 1. Установка и первый запуск

Нужны Ruby 3.4+ и гемы из `Gemfile`: `sqlite3` для журнала, `minitest` для тестов. Рисунки — обычный SVG, отдельный графический гем не нужен.

```bash
bundle install
ruby examples/run_all.rb
```

Девять примеров должны сойтись одной фразой: `Примеры: 9/9 сошлись.`

Один организм из кода:

```ruby
require_relative 'lib/sm_lab'

net = SmLab::SnailHouse.new(neuron_count: 10)
10.times { net.step!(external_input: net.drive_at(net.step_count)) }
peaks = net.history.map do |frame|
  frame[:state].max_by { |neuron| neuron[:activation] }[:id]
end
puts peaks.join(' → ')
puts net.info
```

Пик идёт `0 → 1 → 2 → …`. `drive_at` на нулевом шаге даёт один импульс в первую клетку, дальше — тишина. Горб после этого шагает сам.

Проверка библиотеки:

```bash
ruby test_neuron.rb
ruby test_network.rb
ruby test_matrix.rb
ruby test_applications.rb
ruby test_inhibition.rb
ruby test_store.rb
```

## 2. Нейрон

Класс `SmLab::Neuron`. Три числа состояния:

| Величина | Диапазон | Смысл |
|---|---|---|
| `activation` | 0…1 | возбуждение |
| `fatigue` | 0…1 | усталость, копится от активности и утекает |
| `state` | `dormant` / `active` / `excited` | ярлык по активации |

Порог по умолчанию `0.5`. Выше `0.5` нейрон `active`, выше `0.7` — `excited`. Состояние читается только из активации. Отдых уменьшает усталость и не переписывает состояние.

Нулевой вход остаётся ниже порога. Смещение `bias` по умолчанию `1.1`, поэтому покой — это покой, а не `0.5`.

Один шаг нейрона:

```text
dampener = max(1 − sensitivity × fatigue, 0.05)
raw      = ((вход × dampener) − bias − fatigue_pull × fatigue) × slope
activation = sigmoid(raw)          # аргумент зажат в ±20
fatigue    = clamp(fatigue + gain × activation, 0, 1)
```

Потом сеть вызывает `recover`: усталость умножается на `(1 − recover_rate)`.

Два рычага усталости делают разную работу.

- `fatigue_sensitivity` глушит вход. Так устроен пример привыкания: повтор того же толчка перестаёт доходить.
- `fatigue_pull` дополнительно уводит нейрон в покой. Вместе с взаимным торможением это переключает две группы: победитель устаёт и отпускает соседа. Так устроены походка, кольцо, спираль ДНК, ядро и матрёшка.

Гомеостаз — отдельный слабый сдвиг активации к `0.5` после шага. На одном шаге это доля разрыва, заданная `homeostasis_rate` (у базовой сети `0.02`). Его выключают флагом `homeostasis: false` или нулевой скоростью. У осциллятора и у бегущего горба скорость гомеостаза уже `0`: ритм не подтягивают к середине.

Пресеты лежат в `SmLab::Dynamics`.

Осциллятор, из которого собраны противофазные сети:

```text
bias 0.5, slope 2.5, fatigue_gain 0.12,
sensitivity 0.4, fatigue_pull 3.0, recover 0.1
тонус 3.5, самовозбуждение 2.5, взаимное торможение −4
```

Волна, из которой собран бегущий горб:

```text
bias 1.8, slope 2.0, fatigue_gain 0.01,
sensitivity 0.2, fatigue_pull 0, recover 0.2
вперёд 4.5, назад −1.5, импульс 3.2
```

У волны усталость почти выключена. Иначе горб гаснет на втором шаге. Привыкание, наоборот, держится на сильном `fatigue_pull`.

## 3. Шаг сети

Класс `SmLab::Network`. Шаг дискретный:

```text
вход_i = Σ_j  weights[i][j] × activation_j(прошлый шаг)  +  external_i
```

`weights[i][j]` — насколько нейрон `i` слушает нейрон `j`. Строка — слушатель, столбец — источник. Отрицательный вес тормозит. Положительный возбуждает.

`external_input` — массив той же длины, что `net.size`. Короткий вектор и нечисловое значение поднимают `ArgumentError`. `nil` означает тишину.

Топология строится лениво, на первом `step!`, если веса ещё пустые. После шага кадр попадает в `net.history`: номер шага и `to_h` каждого нейрона (`id`, `activation`, `fatigue`, `threshold`, `state`).

Полезные методы:

| Метод | Что отдаёт |
|---|---|
| `size` | число нейронов после округления решётки |
| `info` | имя, размер, число ненулевых весов, средние, число шагов |
| `mean_activation` / `mean_fatigue` | средние, не суммы |
| `summary_series` | по шагам: средняя активация и усталость |
| `layout` | координаты для рисунка или `nil` |
| `slug` | имя файла вроде `snail_house` |

`FlatGarden` дополняет число нейронов до полного квадрата: запрос `7` даёт сторону `3` и `9` нейронов. `Crystal` дополняет до куба: запрос `20` даёт сторону `3` и `27` нейронов. Длину входа всегда берите из `net.size`.

## 4. Стимулы и два особых режима

Общие входы — `SmLab::Stimuli.generate(тип, длина, шаг)`. Один и тот же шаг и длина дают один и тот же вектор. Случайность локальная, глобальный `rand` процесса не сдвигается.

| Тип | Что это |
|---|---|
| `:silence` | нули |
| `:tonic` | одна и та же константа, по умолчанию `0.4` |
| `:periodic` | синус, общий для всех клеток |
| `:alternating` | `0.1` и `0.7` через шаг |
| `:center_pulse` | фон `0.1`, в середине `0.8` |
| `:spiral` | медленно ползущий уровень |
| `:random` | числа из `0.2…0.5`, seed от номера шага |

Эти входы слабые. На них видно, что сеть жива, и не видно ни бегущего горба, ни противофазы.

Два режима живут в `SmLab::Experiment.run` и в журнал пишутся отдельно.

`:crawl` — один импульс `3.2` в стартовую клетку, дальше тишина. Сеть должна уметь `drive_at`. Так записаны улитка, лабиринт и щупальца.

`:rhythm` — тонус `3.5` с самой сети (`tonic_drive`). Кольцо, спираль ДНК и ядро перед прогоном получают толчок одной группы (`prepare_rhythm!`). Матрёшка толчка не получает: тонус только у внутреннего кольца, дыхание начинается из покоя.

```ruby
net = SmLab::RingDance.new(neuron_count: 8)
SmLab::Experiment.run(net, steps: 80, input_type: :rhythm)
```

Неизвестный тип из общего списка поднимает ошибку. `:crawl` и `:rhythm` в этот список не входят: их понимает только `Experiment`.

## 5. Десять архитектур

Все лежат в `lib/architectures/` и подключаются через `require_relative 'lib/sm_lab'`.

### Бегущий горб

Один импульс, дальше тишина. Следующая клетка слушает текущую с весом `4.5`, предыдущая её гасит.

| Класс | Размер в журнале | Куда идёт пик |
|---|---|---|
| `SnailHouse` | 10 | `0 → 1 → … → 9 → 0`, запас яркости около `0.96` |
| `Labyrinth` | 10 | тот же круг; телепорт — тормозной прыжок вдаль, пик он не крадёт |
| `Tentacles` | 12 | по щупальцам `2 → 3 → … → 11 → 2`; нейроны `0` и `1` — ядро, оно только замечает захват |

Средняя активация такого прогона около `0.12`. Это не «слабая сеть»: горит одна клетка из десяти, остальные молчат. На гистограмме улитки за 40 шагов 360 тихих значений и 40 вспышек около `0.99`. Смотреть надо тепловую карту `plots/*_crawl.svg` или последовательность пиков, а не спарклайн среднего.

Запуск улитки из журнального рецепта:

```ruby
net = SmLab::SnailHouse.new(neuron_count: 10)
SmLab::Experiment.run(net, steps: 40, input_type: :crawl)
```

### Противофаза

Внутри группы возбуждение с суммой `2.5`. Между группами торможение с суммой `-4`. Тонус `3.5` держит цикл, усталость переключает победителя. В журнале это 80 шагов, оценка начинается с 16-го (первые 15 — разогрев).

| Класс | Группы | Доля шагов врозь | Переключений |
|---|---|---|---|
| `RingDance`, 8 | две половины кольца | 85% | 4 |
| `DoubleHelix`, 10 | две цепи, поперёк торможение | 95% | 4 |
| `PulsingCore`, 16 | ядро и периферия | 95% | 4 |
| `NestingDoll`, 12 | внутреннее кольцо и наружное | 100% | 26 |

Матрёшка дышит чаще: тонус только внутри, снаружи её осаживают, толчка нет. Кольцо, спираль и ядро без толчка могут сойтись в ногу — толчок ломает симметрию.

Рисунки групп: `plots/ringdance_rhythm.svg`, `plots/doublehelix_rhythm.svg`, `plots/pulsingcore_rhythm.svg`, `plots/nestingdoll_rhythm.svg`.

Кольцо, спираль ДНК и ядро — один и тот же приём в трёх графах. Различаются форма и подписи групп, не формула ритма.

### Местные правила без бегущего горба

| Класс | Правило |
|---|---|
| `FlatGarden` | четыре соседа по стороне возбуждают (`0.55`), диагонали тормозят (`−0.4`), края замкнуты в тор |
| `Crystal` | сосед по грани куба возбуждает (`0.5`), сосед по ребру тормозит (`−0.28`) |
| `ChaoticBall` | случайный разреженный граф, seed `42`; каждый четвёртый нейрон исходящими связями только тормозит |

Контраст сада проверяется так: центр `3×3` ставят в `1`, остальных в `0.05`, один тихий шаг. Сосед по стороне оказывается около `0.366`, диагональный сосед около `0.190`. Пятно остаётся пятном.

`ChaoticBall` не трогает глобальный `rand`. Две сети с одним seed получают одни веса.

## 6. Что умеют примеры

Каждый пример — класс с методом `demo`. Он возвращает хеш: `:ok`, `:title`, `:text`, иногда `:plot`. Скрипт в `examples/` печатает текст и выходит с кодом `1`, если `:ok` ложно.

```bash
ruby examples/run_all.rb
```

| Запуск | Класс | Что происходит на прогоне |
|---|---|---|
| `examples/gait.rb` | `HalfCenter` | два нейрона, веса `2.5` на себя и `−4` на соседа; после разогрева около 94% шагов врозь и 4 переключения |
| `examples/phototaxis.rb` | `BraitenbergVehicle` | старт `(0, 0)`, свет `(6, 2)`, курс от света; дистанция `6.32 → 0.02`, финиш около `(5.99, 1.99)` |
| `examples/echo.rb` | `DelayLine` | импульс проходит открытую цепочку, пики ровно `0 → 1 → … → 7` |
| `examples/worm.rb` | `Worm` | два кольца в одном теле; стена на `1.00`, тело доходит до `0.88` и финиширует на `−0.88`; касание гасит прямое кольцо и зажигает обратное, веса не меняются |
| `examples/sheet.rb` | `Sheet` | тор `4×4`; восток `0,0 → 0,1 → 0,2 → 0,3`, затем север `3,3 → 2,3 → 1,3 → 0,3`; запас `0.92`. Поворот переназначает, кто слушает горб |
| `examples/anomaly.rb` | `Watchdog` | сад `4×4` молчит (максимум около `0.004`); удар в клетку `5` на следующем шаге зажигает соседа, пик около `0.882` |
| `examples/habituation.rb` | `Habituation` | один нейрон, вес нулевой; серия `0.98 → 0.75 → 0.29 → … → 0.16`, пауза 24 шага (максимум `0.01`), затем `0.95 → 0.56 → 0.24` |
| `examples/rhythm.rb` | `RhythmReader` | три рисунка по 6 тактов; сеть не учится, линейный считыватель на 36 примерах отделяет их от новых с шумом, точность 100% |
| `examples/antagonism.rb` | `Antagonism` | горб улитки, лабиринта и щупалец плюс четыре противофазы и контраст сада |

Сторож — подкласс сада со своей решёткой. Диагональное торможение сада в него не входит: выброс должен дойти до четырёх соседей. Лист тоже подкласс сада, но со связями волны. Обычный `FlatGarden` от этих примеров не меняется.

В примере ритма учится только `SmLab::Readout`: гребневая регрессия один-против-остальных. `fit` принимает матрицу следов и метки, `predict` и `classify` читают новый след. Организм по-прежнему без градиента. Это устройство резервуарной машины: сеть — фильтр, решение снаружи.

Рисунок, если он есть, пишется в `plots/examples/`.

```ruby
report = SmLab::Worm.demo(plot: true)
puts report[:text]
puts report[:plot]
```

## 7. Журнал и рисунки

Один файл: `data/smlab.db`. Таблица `runs` — сводка прогона, таблица `samples` — каждый нейрон на каждом шаге. Каталог `data/` в git не входит.

Полный журнал десяти архитектур:

```bash
ruby generate_data.rb
ruby analyze_data.rb
```

`generate_data.rb` перед записью очищает базу. Рядом появляются CSV и SVG в `plots/`.

| Архитектура | Вход журнала | Шагов |
|---|---|---|
| SnailHouse, Tentacles, Labyrinth | `crawl` | 40 |
| RingDance, DoubleHelix, PulsingCore, NestingDoll | `rhythm` | 80 |
| FlatGarden | `center_pulse` | 50 |
| ChaoticBall, Crystal | `random` | 50 |

`analyze_data.rb` печатает сводную таблицу, для `rhythm` — долю шагов врозь и спарклайны двух групп, для улитки — путь горба и гистограмму. Спарклайн среднего у улитки почти ровный: шкала растянута от минимума серии к максимуму, а среднее само по себе мало меняется.

Свой прогон в ту же базу:

```ruby
require_relative 'lib/sm_lab'
require_relative 'lib/store'

net = SmLab::SnailHouse.new(neuron_count: 10)
SmLab::Experiment.run(net, steps: 20, input_type: :crawl)

store = SmLab::Store.new
store.record_run(
  name: net.name,
  neuron_count: net.size,
  input_type: :crawl,
  frames: net.history
)
puts store.latest_summaries.map { |row| [row[1], row[3]] }
```

`Store.new` без аргумента открывает `data/smlab.db`. Свой путь нужен в тестах, чтобы не затереть журнал. `latest_summaries` берёт последний прогон каждого имени. `series(run_id)` — средние по шагам. `activations(run_id, step)` — вектор одного шага по возрастанию `neuron_id`.

Команды экспериментатора пишут в тот же файл:

```bash
ruby experiments/runner.rb --help
ruby experiments/runner.rb --single ring 40 8
ruby experiments/runner.rb --all
ruby experiments/runner.rb --compare
```

`--single` и `--all` по умолчанию кормят сеть слабым `:random`. Для кольца это не противофаза. Противофазу и ход смотрите через `generate_data.rb` или `Experiment.run` с `:rhythm` и `:crawl`. `--compare` показывает последние строки базы и не запускает сети заново.

Имена для `--single`: `snail`, `ring`, `garden`, `doll`, `chaotic`, `crystal`, `tentacles`, `helix`, `core`, `labyrinth`.

Рисование без журнала:

```ruby
SmLab::Plot.sparkline([0.1, 0.4, 0.9, 0.2])
SmLab::Plot.series_svg(
  { 'Активация' => acts, 'Усталость' => fats },
  'plots/my.svg',
  title: 'Мой прогон',
  y_label: 'Уровень'
)
SmLab::Plot.heatmap_svg(rows, 'plots/my_heat.svg', title: 'Кадры', y_label: 'шаг')
SmLab::Plot.trail_svg(points, 'plots/my_trail.svg', title: 'След', target: [6, 2])
```

`rows` для тепловой карты — массив кадров, кадр — массив активаций. `trail_svg` рисует ломаную по парам координат; так устроена картинка фототаксиса.

## 8. Своя топология

Минимальная сеть — подкласс `Network` с `build_topology`. Веса — квадрат `size × size`.

```ruby
class Pair < SmLab::Network
  def initialize
    super(
      name: 'Pair',
      neuron_count: 2,
      neuron_options: SmLab::Dynamics::OSCILLATOR,
      recover_rate: 0.1,
      homeostasis_rate: 0.0
    )
  end

  def build_topology
    @weights = [
      [SmLab::Dynamics::SELF_EXCITATION, SmLab::Dynamics::RECIPROCAL_INHIBITION],
      [SmLab::Dynamics::RECIPROCAL_INHIBITION, SmLab::Dynamics::SELF_EXCITATION]
    ]
  end
end

net = Pair.new
SmLab::Dynamics.kick(net, high: [1], low: [0])
80.times { net.step!(external_input: [SmLab::Dynamics::TONIC, SmLab::Dynamics::TONIC], homeostasis: false) }
puts net.neurons.map { |neuron| neuron.activation.round(3) }.join('  ')
```

Это та же пара, что у походки. Толчок обязателен: из одинакового покоя оба нейрона идут вместе.

Чеклист, если новая сеть «молчит» или «орёт хором»:

1. Длина `external_input` равна `net.size`, не запрошенному числу нейронов.
2. Вес стоит в строке слушателя. Чтобы клетка `i + 1` подхватила горб в `i`, пишите `weights[i + 1][i] = 4.5`.
3. Для бегущего горба берите `Dynamics.wave`, импульс один раз, дальше нули. Тонус `3.5` на волне зажигает всех.
4. Для противофазы берите `Dynamics.tune`, тонус `3.5` и `Dynamics.kick` в одну группу. Без толчка симметрия часто не ломается.
5. Гомеостаз с ненулевой скоростью тянет активацию к `0.5` и размывает и горб, и противофазу.
6. Среднее по сети прячет одиночный пик. Печатайте индекс максимума или две группы через `Dynamics.mean_series`.

Оценка, которой пользуется журнал:

```ruby
frames = net.history.map { |frame| frame[:state].map { |neuron| neuron[:activation] } }
left = SmLab::Dynamics.mean_series(frames, [0])
right = SmLab::Dynamics.mean_series(frames, [1])
window_l = left.drop(15)
window_r = right.drop(15)
puts SmLab::Dynamics.opposed_fraction(window_l, window_r)
puts SmLab::Dynamics.flips(window_l, window_r)
```

`opposed_fraction` считает долю шагов, где группы разведены больше чем на `0.25`. `flips` считает, сколько раз лидер сменился.

Для горба на кольце с номерами `0…n-1`:

```ruby
peaks = frames.map { |row| row.each_with_index.max_by { |value, _i| value }.last }
puts SmLab::Dynamics.advance_fraction(peaks, (0...net.size).to_a)
```

Доля `1.0` значит: каждый шаг пик сдвинулся ровно на одну позицию вперёд по заданному порядку. У щупалец порядок — `tentacle_indexes`, не все нейроны подряд. Ядро в эту оценку не входит.

## 9. Упражнения

1. Запустите улитку на 15 шагов с `:crawl` и напечатайте индексы пиков. Затем замените вход на `:periodic` той же длины. Сравните путь пиков и среднюю активацию.
2. Создайте `FlatGarden` с `neuron_count: 7` и `Crystal` с `neuron_count: 20`. Напечатайте `size`. Объясните, почему вектор длины 7 на сад не подходит.
3. Запустите `Habituation.demo` и выпишите ответ на первый толчок, на последний толчок серии и на первый толчок после паузы.
4. Соберите `Pair` из главы 8. Уберите `kick` и прогоните те же 80 шагов. Посмотрите, осталась ли смена лидера.
5. Повторите контраст сада: девять клеток, центр в `1`, остальные в `0.05`, один шаг с нулевым входом и `homeostasis: false`. Сравните нейрон `1` и нейрон `0`.

## 10. Перспективы

Библиотека на версии `0.9.0` уже показывает набор отдельных поведений. Внутри них повторяются два механизма.

Первый — горб, который за такт шагает к соседу с сильной связью `4.5`, пока хвост заторможен. На нём стоят эхо, улитка, лабиринт, щупальца, червь и лист.

Второй — две группы с взаимным торможением и усталостью победителя. На нём стоят походка, кольцо, спираль ДНК, ядро и матрёшка. Три графа из этого списка отличаются рисунком связей, не правилом ритма.

Дальше имеет смысл собирать из этих двух механизмов новое поведение, а не шестой костюм того же ритма.

Ближние задачи, которые код ещё не закрывает:

- Кристалл задаёт грани и рёбра куба, но горб по нему не ходит. Это тот же шаг, что на листе, только к соседу по грани. Отдельного примера нет.
- Лист поворачивает, переписывая веса. Червь поворачивает стимулом: касание гасит одно кольцо и зажигает другое. Поворот листа таким же касанием, без смены матрицы, в коде не сделан.
- Сад, клубок и кристалл в журнале остаются на слабом входе. У них нет ни `:crawl`, ни `:rhythm`, и сводка по ним показывает покой под шумом, а не отдельный трюк.
- Привыкание, сторож и червь живут в разных примерах. Связка «датчик привыкает и перестаёт разворачивать червя» или «сторож выпускает горб только на редкий выброс» была бы новым поведением из уже готовых частей.

Дальше по духу библиотеки, если продолжать исследования:

- Резервуар. `RhythmReader` уже отличает три коротких рисунка. Следующий честный шаг — больше рисунков или более длинная линия, при том же правиле: учится только внешний `Readout`.
- Несколько горбов на одном листе. Сейчас по листу идёт один. Встретятся ли два импульса, погасят ли друг друга, зависит от бокового торможения и ещё не измерено.
- Тело с двумя моторами. Фототаксис уже везёт точку к свету, походка уже мигает противофазой, вместе они не собраны: машина не шагает ногами к лампе.

Чего библиотека не обещает: обучения внутри организма, больших корпусов, продакшен-сервиса и «ещё одной архитектуры», которая снова мигает двумя половинами. Полезный следующий пример узнаётся так: его нельзя получить, переименовав кольцо или улитку.
