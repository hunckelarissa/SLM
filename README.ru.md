# SLM — сверхмалые нейронные сети

[English](README.en.md)

Два независимых эксперимента на Ruby о том, что происходит, когда сеть
намеренно крошечная, а форма связей — главный объект исследования.
Ни один из них не претендует на продакшен и на модели языка: оба смотрят
на ритм, память, задержку и поведение, которые даёт граф из единиц и десятков
нейронов.

| | [sm_lab](sm_lab/) | [snail_networks](snail_networks/) |
|---|---|---|
| Идея | Цифровой организм: возбуждение, усталость, покой | «Улитка»: топология как предмет обучения и динамики |
| Обучение внутри сети | Нет | Эволюция, SGD, BPTT |
| Нейрон | Активация, усталость, порог, гомеостаз | `tanh` / `sigmoid` / `linear`, синапсы и смещения |
| Форм | 10 архитектур | 12 топологий |
| Ruby | 3.4+ | 3.0+ (проверено на 3.4) |
| Тесты | minitest | RSpec |
| Подробно | [README](sm_lab/README.md), [учебник](sm_lab/УЧЕБНИК.md) | [README](snail_networks/README.md), [учебник](snail_networks/docs/uchebnik.md) |

## Общая постановка

Обычная сеть — слои и градиент. Здесь связь идёт иначе:

- сеть маленькая нарочно (порядка 8–20 нейронов, далеко меньше 10 000 параметров);
- топология не скрыта за слоями — кольца, спирали, кубы, ленты, сады;
- время дискретно: шаг читает прошлые активации, затем все обновляются вместе;
- вопрос не «насколько большой моделью закрыть бенчмарк», а «какую динамику
  уже несёт форма графа».

Два подпроекта отвечают на этот вопрос с разных сторон и **не зависят** друг
от друга: общий только репозиторий и интерес к сверхмалым сетям.

## sm_lab — организмы без обучения

> «Мы не строим ИИ. Мы выращиваем цифровые организмы на дискете.»

Нейрон — короткий организм. Он возбуждается, устаёт и медленно возвращается
к покою. Веса могут тормозить. Сложного поведения добиваются топологией,
усталостью и внешним стимулом — без градиентов внутри сети.

Уже есть походка, фототаксис, эхо-память, ползание горба, привыкание, ритм
с внешним считывателем.

```bash
cd sm_lab
bundle install
ruby examples/run_all.rb
ruby experiments/runner.rb --all
```

## snail_networks — форма связей и обучаемость

«Улитки» сравнивают, как кольцо, звезда, куб или лента Мёбиуса держат импульс,
учатся задержке и разделяют знаковые таблицы. Один такт у всех форм общий;
меняются только рёбра и способы учить веса.

```bash
cd snail_networks
bundle install
rake test
rake examples
rake run_all
```

## Когда какой брать

- Нужен **живой цикл без обучения** — ритм, торможение, усталость, таксис —
  смотрите `sm_lab`.
- Нужно **сравнить топологии на обучении** — задержка, эхо, XOR, маршруты
  импульса — смотрите `snail_networks`.
